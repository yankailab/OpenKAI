Create an OpenKAI config

  1. Add classes from the library. Categories follow the source folders.
  2. Select a node to name it and edit its parameters. Optional values can be omitted to use the runtime defaults. Arrays and objects accept JSON.
  3. Click or drag a dependency port on the right of a node, then choose a compatible provider. Arrows point from the provider to the instance that retains its pointer. Connections can also be added and removed in the inspector.
  4. Open or paste existing JSON to edit it. Use Edit JSON for the whole document, including fields outside module objects.
  5. Copy or download the usual config JSON and launch OpenKAI with it. Canvas layout is kept separately from the config.

Use Arrange / Fit to organize the canvas. Undo and redo cover config edits. Your latest work is saved locally in this browser when storage is available.

Class availability depends on your OpenKAI build flags. Include files remain external; references into them appear unresolved. Base and helper classes are listed for reference.
